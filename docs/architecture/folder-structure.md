# Folder structure

```
.
├── README.md                     # run/test instructions, PR table, video link
├── index.html
├── package.json
├── tsconfig.json                 # strict
├── vite.config.ts                # also holds the Vitest config
├── eslint.config.js
├── public/
│   └── mockServiceWorker.js      # generated by `npx msw init public`
└── src/
    ├── main.tsx                  # starts MSW in dev, mounts <App/>
    ├── app/
    │   ├── App.tsx               # providers: QueryClient(Persist)Provider, RouterProvider
    │   ├── router.tsx            # one route per question + Q2 detail route
    │   ├── queryClient.ts
    │   └── Layout.tsx            # nav + <Outlet/> + <ScrollRestoration/>
    ├── mocks/
    │   ├── handlers.ts           # aggregates feature handlers
    │   ├── browser.ts            # setupWorker(...handlers)
    │   └── server.ts             # setupServer(...handlers) for tests
    ├── shared/
    │   ├── ui/                   # small primitives (Button, Spinner, ErrorWithRetry, EmptyState)
    │   └── lib/                  # cross-feature helpers once a second feature needs them
    ├── test/
    │   ├── setup.ts              # jest-dom, MSW server lifecycle, storage reset
    │   └── renderWithProviders.tsx
    └── features/
        ├── cart/                 # Q1  route /cart
        ├── feed/                 # Q2  routes /feed, /feed/:postId
        ├── kanban/               # Q3  route /kanban
        ├── dashboard/            # Q4  route /dashboard
        └── comments/             # Q5  route /comments
```

Each feature folder:

```
features/<feature>/
├── domain/            # pure functions + types, one per file
├── application/       # hooks, stores, query options
├── infrastructure/    # api client, zod schemas, msw handlers (mocks.ts)
└── interface/         # <Feature>Page.tsx + components, *.module.css
```

## Conventions

- One unit per file; file name = unit name (`calculateTotals.ts`, `CartPage.tsx`). Max 120 chars per line, 400 lines
  per file.
- Tests sit next to the unit: `calculateTotals.test.ts`, `CartPage.test.tsx`.
- Path alias `@/` → `src/`.
- Route paths: `/cart`, `/feed`, `/feed/:postId`, `/kanban`, `/dashboard`, `/comments`; `/` redirects to `/cart`.
