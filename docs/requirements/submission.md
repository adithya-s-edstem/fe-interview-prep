# Submission

README, video, timing and the final checklist. Source: assignment "Overview", "Submission workflow", "Video
guidelines" and "Submission checklist".

## Time limits

- 2 hours for all 5 questions, including PRs and merges.
- Suggested split: Q1 and Q2 15 minutes each, Q3 and Q4 25 minutes each, Q5 40 minutes.
- 30 more minutes after the cut-off to record and upload the video.

## README

Keep the README updated as each PR merges. It must contain:

- How to run the app and the tests.
- This table, with every PR link filled in:

- A final `Video:` line with the YouTube link, added after the last merge.

## Video

- One screen recording, at most 2 minutes, covering all 5 questions, recorded after the last merge.
- Uploaded to YouTube as **Unlisted**; link added to the README.
- Running order:

| Time | What to show |
|---|---|
| 0:00–0:10 | Quick tour of the repo and the merged PRs |
| 0:10–1:50 | About 20 seconds per question: what it does, and the most important decision made |
| 1:50–2:00 | One thing to improve with more time |

- No line-by-line walkthrough: show the one piece of code that matters most per question and say why.
- Any recorder (Loom, OBS, QuickTime, built-in). Face camera optional; voice clear; editor font zoomed to at least 16px.

## Interview readiness

- Be ready to explain every decision and the alternatives considered, and to make a short live change.
- Be able to explain every file in the repo without AI help.

## Submission checklist

- **S-AC1** Public repo `fe-interview-prep` created, with a README.
- **S-AC2** 5 branches, 5 PRs, all merged into `main`.
- **S-AC3** Every PR uses the description template and includes screenshots or a GIF.
- **S-AC4** The README explains how to run the app and the tests.
- **S-AC5** Tests, lint and type-check all pass.
- **S-AC6** Code and PRs done within 2 hours; one video of at most 2 minutes uploaded to YouTube (Unlisted) within 30
  minutes after.
- **S-AC7** The README has every PR link and the YouTube link.
- **S-AC8** The author can explain every file in the repo without AI help.
